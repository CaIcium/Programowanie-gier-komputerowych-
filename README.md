# Programowanie-gier-komputerowych-
## Co zostało zrealizowane
Na początek utworzyłem klasę bullet w pliku bullet.py. Klasa ta odpowiada za rysowanie pocisku, aktualizowanie pozycji pocisku kiedy leci, płynną teleportacje pocisku kiedy wyleci za mapę. Następnie musimy dodać możliwość wystrzeliwania pocisku z statku, w tym celu trzeba było zaaktualizować kod w main.py. Dodałem jeszcze dźwięki wybuchu i strzału. Kolejnie dodałem teksturę tła, jest to poprostu nałozony plik .jpg. Następnie musiałem wykonać kolizję pocisku z asteridą, w tym celu zaaktualizowałem plik utils.py gdzie jest funkcja która sprawdza czy kolizję dwóch okregów. Na koniec dodałem plik explosion.py, tam znajduje się funkcja która rysuje eksplozję kiedy pocisk trafi w asteroidę.
## Uruchomienie 
Aby uruchomić gre trzeba pobrać cały wszystkie pliki z lab_07 i następnie najlepiej VisualStudioCode otworzyć folder tej gry i odpalić plik main.py.
